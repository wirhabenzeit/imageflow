# The workspace

## Toolbar and menus

The title bar shows the document name and icon, Undo, Redo and Export. Command-click the name to see its location.

| Menu | Commands |
| --- | --- |
| File | New Book ⌘N, Open ⌘O, Duplicate ⇧⌘S, Rename, Move To, Revert To, Export PDF ⌘E, Export Proof ⌥⌘E |
| Book | New Spread ⇧⌘N, Duplicate Spread ⌘D, Move Up/Down ⌥⌘↑ / ⌥⌘↓, Delete Spread ⌫, Check Book ⇧⌘K |
| Assets | Import ⇧⌘I, Import Selected from Lightroom Classic, Manage Assets, Copy Assets into Book |
| Templates | Manage Templates… |
| View | Canvas layout, guides, panels, zoom, photo sorting and grouping, presentation |

Text fields use the system's text Undo. Other edits use the book's Undo history.

## Panels and sources

The left sidebar holds spread thumbnails and book settings. The right sidebar is the Inspector. Toggle them with the toolbar buttons or **View → Show/Hide Sidebar** (⌃⌘S) and **Show/Hide Inspector** (⌥⌘I).

The **Photos / Texts / Assets** strip holds the book's sources. **Assets**, shown when the template has file parameters or the book holds files, is a plain list of those files, such as GPX tracks, each with its macOS document icon. It has the same search, filters and actions as **Assets → Manage Assets…**, which lists every asset, and **Import…** or a drop from Finder adds files of the types the template accepts. Toggle it with ⌥⌘3. Select a source and press Space, or double-click it, for Quick Look. **View → Sort Photos By** and **Group Photos** control the photo list.

Drag dividers to resize panels. With a divider focused, use arrow keys to resize or Home to reset; double-clicking also resets it. Sizes are remembered on this Mac.

## Canvas and presentation

**View → Vertical** stacks spreads in one column. **Grid** uses one to four columns, selected under **View → Columns**. **View → Show Guides** toggles guides. Each book remembers its canvas layout on this Mac.

The canvas starts in **Fit**, centred with vertical scrolling. Pinch over the paper, use the **− / +** controls at the lower right, or press **⌘− / ⌘+** to zoom temporarily. The percentage is relative to Fit. When enlarged, scroll in either direction with the trackpad, or hold **Space** and drag to pan with a mouse. **Return to Fit**, **View → Zoom to Fit**, or **Escape** while the canvas is focused restores the fitted view and the reading position where zoom began. Escape closes an open editor first. Zoom is not saved with the book. While cropping a photo, pinching over it continues to adjust that photo's crop.

Choose **View → Presentation** (⇧W) to present from the current spread, or **Present from Beginning** (⌥⇧W). A book with a cover layout starts with its exterior cover, which also opens the presentation from the Cover view. Presentation opens a separate fullscreen window on the editor's display. Changes saved meanwhile, by you or an agent, show in it as they render. Escape or Close Window dismisses it and returns to the last viewed spread. Closing the book closes its presentation; starting from another book switches to that book.

## Appearance

**ImageFlow → Settings…** (⌘,) opens settings. Under **General**, choose Light, Dark or System. This changes the app's appearance; book pages and PDFs keep the template's colours.

For automatic update checks, Stable/Beta channels and **Restart to Update**, see [Updates](getting-started.md#updates).
